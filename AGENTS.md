# CodeLab — interface React do TCC

- Este é o repositório local independente `codelab-web`, autorizado pelo usuário ao priorizar a interface do MVP. Backend NestJS em `../codelab-api`, executor Ruby em `../judge0`. Não recriar monorepo nem importar fontes, Prisma ou configurações privadas dos outros checkouts.
- Ler `README.md`, `docs/F01_INTERFACE_REACT.md`, `docs/F02_TURMAS_MATRICULAS.md`, `docs/F03_EXERCICIOS_VERSOES.md`, `docs/F04_CASOS_PREVIA.md`, `docs/F05_ATIVIDADES.md` e as skills locais `tcc-frontend-react` e `tcc-plataforma-typescript`, incluindo suas referências pertinentes.
- Stack: React/TypeScript estrito, Vite e CodeMirror. Organização por funcionalidade; `App` compõe a página, `useExecution` controla envio/consulta e o cliente de API valida JSON em runtime. Navegação entre prática e turmas usa rotas hash; sessão tem Context, sem store global de dados.
- A interface consome somente `/api` do NestJS via proxy. Não chamar Judge0 diretamente, expor suas chaves/tokens ou incluir casos ocultos no bundle. Exemplos locais são públicos, uma execução por caso, sem aluno/atividade/nota.
- F02 entregue: login/logout B05 e turmas/matrículas B06 reais. Professor administra seus vínculos; aluno consulta suas turmas sem roster. F03 integra a B07 e F04 integra a B08: autoria, versões, visibilidade e prévia segura. F05 integra atividades B09 por turma: criação com versão publicada, abertura/encerramento e leitura pública para matrícula ativa. Próxima tarefa do backend é B10; entregas e indicadores permanecem posteriores.
- Preservar o snapshot enviado separadamente do rascunho editável. Resultado antigo não pertence ao código novo. Falhas operacionais/timeout não viram resposta errada; nunca repetir POST automaticamente. Retomada usa GET do ID público.
- Polling tem prazo, intervalo e cancelamento ao desmontar. Não interpretar parada da consulta como cancelamento do programa no Judge0. Rascunhos/último ID ficam neste navegador; o PostgreSQL continua sendo fonte de verdade do resultado.
- Código, stdout e diagnósticos são texto, sem `dangerouslySetInnerHTML`. Manter labels, teclado, foco, mensagens textuais e layout móvel.
- Testes normais interceptam somente `/api` e não enviam programas reais. `npm run test:real` usa a stack Docker ativa e cria apenas execuções sintéticas; distinguir sua evidência dos mocks. Checar tipos, build e formatação.
- Repositório somente local; não criar remoto, novo commit ou publicação sem solicitação. Configurações privadas em `.local`/ambiente, ignoradas por Git e Docker.

- Sessão/CSRF apenas em memória, cookie HttpOnly pelo navegador; respostas 401/expiração retiram a visão privada. Contratos públicos validados em runtime, sem imports do backend. Consultas abortam ao sair e mutações não têm retry automático. `npm run test:classrooms:real` usa somente TEST_DATABASE_URL em stack PostgreSQL/tmpfs descartável com fixtures sintéticas; não usar banco de desenvolvimento como teste.
- Exercícios: somente professor autor recebe dados pela API; o guard visual não substitui a autorização B07. Alterações não salvas pedem confirmação ao sair. Publicação usa somente conteúdo salvo; edição exige abrir rascunho. Histórico é leitura e rascunhos com publicação anterior não podem ser excluídos. O editor CodeMirror compartilhado está em `shared/ui`, sem duplicação da prática.
- `npm run test:questions:real` reutiliza a stack descartável de turmas, nas mesmas portas 3006/5176; executar separadamente. Não usa Judge0, dados reais ou banco de desenvolvimento. F04 integra casos PUBLIC/HIDDEN e política `judge0_text_rstrip_v1`; limites publicados ainda não alteram a prática E01.
- F04 requer API B08. Nunca assumir PUBLIC quando uma resposta de autoria omite visibility; sempre enviar visibility e comparisonPolicy explicitamente. Publicar exige caso público salvo. Prévia consulta somente `/api/questions/:id/versions/:numero/preview`, sem buscar a versão docente e filtrar no cliente. Contrato discente próprio rejeita campos inesperados; a autorização continua no servidor. Não persistir casos em storage nem ligar ocultos à prática anônima.

- F05 usa apenas resumos de exercícios/versões no seletor e a projeção pública de `/api/activities/:id` no detalhe, inclusive para o professor. O aluno nunca consulta `/api/questions`. Versões anteriores de exercícios em revisão continuam elegíveis; enviar o UUID da versão, sem trocar pelo ID do exercício ou número. Encerramento é definitivo; não oferecer reabertura/edição/exclusão/envio sem contrato correspondente.
- `npm run test:activities:real` usa a mesma stack descartável/portas 3006/5176 dos outros testes educacionais; executar separadamente. Não repetir POST automaticamente; após confirmação perdida, consultar por GET antes de nova ação. Usar Conventional Commits com mensagens em inglês quando o usuário solicitar commit.
